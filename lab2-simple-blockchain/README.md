# Lab 2: Simple Blockchain Ledger

## Objective

This lab teaches students how blocks connect together using previous hash.

## What Students Learn

- What is a block
- What is previous hash
- What is current hash
- How blockchain detects data changes
- Why changing old data makes the chain invalid

## How to Run

```bash
python simple_blockchain.py
Learning Point

If old block data is modified, the blockchain becomes invalid because the hash changes.
